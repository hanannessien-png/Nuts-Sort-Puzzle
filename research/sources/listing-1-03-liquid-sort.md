## 🧪 A liquid sort game about planning, not speed

Each level hands you a row of bottles filled with stacked layers of colour, four to a bottle, all mixed up, plus a little empty space to work with. Tap one bottle, tap another, and the top colour pours across. When every bottle holds a single colour, the level is done.

There is no timer and no move counter watching you, so the only pressure is the board itself. Early levels clear in a few pours. Later ones add colours while keeping the spare room tight, and that is where the game turns into planning: the pour that looks helpful now is often the one that leaves you with nowhere to put the last colour.

## 🎮 How to Play

- **Tap a bottle, then tap where it should go.** That is the only move in the game.
- **Match the top colour.** Liquid can land on a layer of the same colour, or in an empty bottle.
- **Watch the space.** A bottle holds four layers, and a pour stops when the target is full.
- **Runs move together.** Two or three matching layers on top pour as one block if there is room for them. If there is not, part of the run stays behind, and that split is the most common way a board goes wrong.
- **Restart whenever you like.** If a level has tied itself in knots, start it fresh and look at the opening board again.

## 💡 The habit that clears hard levels

Before you pour into an empty bottle, name the move it opens up. Empty bottles are the only room you have to manoeuvre, and parking a colour there "for now" is how most boards get stuck. Merge matching tops first, finish bottles that are one layer from done, and only then spend an empty one.
