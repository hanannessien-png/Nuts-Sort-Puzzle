Need personal therapy? Play Nut sort - Nuts Sort Puzzle. This test bolt game is a great stress and anxiety relief. Fill tubes and get inspired by thousands of colors. Nut sort - Nuts Sort Puzzle is designed to relax.

Play Nut sort - Nuts Sort Puzzle. Get a personal relaxing pour game with a broad range of levels. Find the most interesting nut puzzle games and sort nuts any time, whenever you feel down.

How to play a nut sort puzzle?
Tap any test bolt to move color nut to another test tube.The rule is that you can only pour the nut if it is linked to the same color and there's enough space on the bolt.
